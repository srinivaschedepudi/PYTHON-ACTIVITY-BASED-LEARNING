# Python Activity-Based Learning

## About This Project
This repository contains 10 Python case studies completed as part of my Python Activity-Based Learning assignment.

Each case study focuses on solving a practical problem using Python programming concepts, algorithms, and logical thinking.

## Project Contents

### Python Source Code
Contains the Python source code files for the 10 case studies.

### PDF Reports
The `case-report` folder contains PDF reports documenting the case studies.

Each report may include:
- Problem Statement
- Objectives
- Assumptions
- Algorithm
- Flowchart
- Pseudocode
- Python Source Code
- Test Cases
- Output Screenshots
- Conclusion

## Technologies Used
- Python
- Git
- GitHub

## Purpose
The purpose of this project is to improve Python programming skills, problem-solving ability, algorithm design, and practical application development.
